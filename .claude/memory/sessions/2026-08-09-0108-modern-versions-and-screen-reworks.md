## Gotchas & dead ends
- **I overrode the user on the combo-box version twice and was wrong both times.** I "grounded"
  `@1.0.0` on a stale MS Learn YAML sample plus a paste failure that had actually happened while
  modern controls were still *disabled* in the app. The rule I wrote into the skill from that
  ("never derive a version from Studio's UI") was retracted. Lesson: a paste failure only
  implicates the token if modern controls were enabled at the time.
- **Sibling modern controls do NOT share property names.** `ModernTextInput` takes
  `Type: =TextInputType.Multiline` (NOT `Mode`/`TextMode` — classic) and
  `TriggerOutput: =TriggerOutput.Delayed` (NOT `DelayOutput` — that's the combo box's). I shipped
  both wrong properties; the user hit them.
- **A file that EMITS pa-yaml is bound by the same token rules as pa-yaml.** The version sweep
  hit `src/` but not the Python generator, so regenerating quietly reintroduced
  `ModernTextInput@1.0.0` / `ModernButton@1.0.0`. The allow-list caught it. Sweep generators too.
- **`FillPortions` defaults to 1 at EVERY nesting level** — one unpinned ancestor undoes all
  pinning below. Cost two rounds on the staged galleries ("only 3 of 6 rows", then "the 2nd is
  cut off"): first the column, then `rowPrStaged` itself.
- **`TemplatePadding` is taken off BOTH edges** — usable cell height = `TemplateSize − 2×`.
  A 30px chip in `TemplateSize 34, padding 4` gets 26px and clips.
- **`ModernTabList.Default` must be an ITEM** (`=First([...])`); `ModernDropdown.Default` takes a
  **value**. The user diagnosed this one.
- **"The value xxxx cannot be converted to a number"** = a number laundered through a Label's
  `Text` and read back with `Value()` (×12 in `cmpNestedSelect`). Compute the seed depth inline;
  don't park numbers in text.
- **`Patch()`'s return is an ID receipt, not a full record.** Three readers of `gPrSaved` broke on
  `project_name`; re-read the row with `LookUp` before seeding anything from it. The user's clue
  that cracked it: *"the bug is fixed when I remove the single task added to the project."*
- **`"Project_Type" is required` was a SharePoint problem, not a code problem** — a retired
  Managed Metadata column still Required on the list. Deliberately did NOT author the retired
  column to satisfy it.
- **`FillPortions` / `LayoutMinWidth` are not accepted on a `CanvasComponent` instance** — wrap it
  in a pinned `GroupContainer`.
- `Icon.TrashCan` is not among the 180 grounded icons → `Icon.Warning`. Validator caught it.
- A section's toggle row must **never** be gated on its own toggle — that hides the only way to
  switch the section back on. Gate the field rows only.
