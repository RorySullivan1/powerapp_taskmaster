## The finding that made the distillation trivial
**Every load-bearing invariant the comments explained was ALREADY recorded** — in
`.claude/memory/`, in a `.claude/skills/` SKILL.md, or in `docs/reports-screen-design.md`.
Checked all eight of the big ones (locale-decimal SVG trap, the gallery N+1 rule, Select()
queues, no component in a gallery, Max(1,..) at the point of division, the circumference-100
pie, Explicit Column Selection, cumulative-not-independent bar boundaries) — all eight hit.
So the purge was **delete, not migrate**: the comments were the undistilled copy of notes
that already had a better home.

## What was actually removed
1. **Verbatim repeats.** The single biggest category. Examples: the sort-button note x7 in
   scrReports; the pie-construction essay x2 and the slice-geometry note x4 in the same file;
   the three gallery-row rules x3 each in scrProject; the `colDueSrc` fold note x2 in scrHome
   (OnVisible and the Refresh OnAction); the 8-line double-tap guard x5 across the editors;
   the 9-line appBar note x3. **Fix: state it once in the file header, delete at the sites.**
2. **Changelog prose**, already forbidden by CLAUDE.md and never enforced. scrTaskEdit's
   33-line header was literally "REWORKED 2026-08-07 / WHAT CHANGED"; cmpToast's 56-line
   header was 40% "why the redesign".
3. **Rot.** Three stacked generations of contradictory comment sat above `gPrPriority` in
   scrProjectEdit — one of them described a phase control the screen no longer has.

## Negative-space notes deleted (recorded here so they are not re-derived)
- **`gProjArchived` on scrProject.** Removed 2026-08-12. It counted this project's
  individually-archived TASKS, but `task_stage` has no "Archived" value, so the query could
  only ever return 0 and the "N archived (hidden)" caption it fed could never render.
  Nothing is hidden from the task list: it is every task on the project.
- **The old `scrTask` detail screen** (deleted 2026-08-10) seeded every control from
  `Default` and never called `Reset()`, so the second task opened still showed the first
  task's values and saving wrote them back. It is why every editor now Resets in OnVisible.
- **scrProjectEdit's archive cascade** is gone with the phase control. The external cleanup
  flow owns BOTH halves — `project_phase = "Archived"` AND the three `*_project_archived`
  child flags. This IS still stated in the file; the history of its removal is not.

## Method (reusable)
`/tmp/.../scratchpad/purge.py` — an applier taking `{(start,end): [replacement lines]}` per
file, re-applying the original indent and comment marker, then asserting the non-comment
lines are byte-identical to `git show HEAD:<path>`. That assertion is what makes a
1000-line edit safe to do with a script instead of by hand.

## Not done
