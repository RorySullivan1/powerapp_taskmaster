# 1 · The repo and where authority sits

## Layout

```
src/App.pa.yaml        the App object — OnStart constants and the Formulas data-source filters
src/Screens/           one file per screen (11)
src/Components/        one file per component (10); definition and controls in the same file
schema/schema.yaml     GOLDEN SOURCE for the SharePoint backend
schema/incoming-lists.md   provenance: which screenshot each list came from
tools/                 the validator, the vendored pa-yaml schema, the grounded token list, audits
docs/                  design notes, build history, and these manuals
tests/                 throwaway probe screens — NOT app source
.claude/               skills, agents, commands, workflows, context briefs, memory, hooks
```

Everything under `src/` is [pa-yaml v3.0](https://github.com/microsoft/PowerApps-Tooling) — the
same dialect Studio's code view emits.

## Who defines what

| Thing | Authority | The downstream copy |
|---|---|---|
| App source | `src/**.pa.yaml` | The app in Studio |
| SharePoint lists and columns | `schema/schema.yaml` | The live lists |
| Decisions and their reasoning | `.claude/memory/` | — |
| What has actually landed in the app | `docs/build-history.md` | — |
| Hook configuration | `.claude/hooks/*.json` | `.claude/settings.json` (generated) |
| Asset inventory | generated by `.claude/hooks/catalog.py` | `.claude/CATALOG.md` |

Two of those inversions are worth stating plainly, because they are the opposite of the usual
arrangement:

- **The repo defines the app**, and Studio applies it. Anything edited directly in Studio is
  drift the repo can never see — see [chapter 2](02-the-air-gap.md).
- **The repo defines the schema**, and SharePoint is provisioned to match — see
  [chapter 4](04-schema-changes.md).

## What is deliberately not here

- **The running app.** It lives in Studio on the work machine. This repo cannot query it.
- **A build.** There is nothing to compile and nothing to deploy. "Shipping" is a human pasting.
- **Tests of the app.** `tests/` holds *probe screens* — throwaway screens pasted into Studio to
  settle one question about Studio's behaviour. Nothing in `src/` may reference one, and the
  validator scans `src/` only. `tests/README.md` has the rules and the recorded answers.
- **Power BI.** Out of scope since 2026-08-17. Every chart in the app is SVG drawn in Power Fx.
